GDG DevCamp — the four pillars

Google's Gemini Enterprise Agent Platform, one pillar at a time, applied to this agent. Each lab is Theory + Workshop + a self-directed Assignment.

  • Lab 1
    Build
    ADK, Model Garden, Agent Skills, tools, MCP toolsets — design and compose the agent.
  • Lab 2 · after Session 2
    Scale
    Agent Runtime, Agent Identity, Sessions, Memory Bank — run the agent on the managed runtime.
  • Lab 3 · after Session 3
    Govern
    Model Armor, Cloud DLP, Governance Policies, Agent Registry, Agent Gateway — control what the agent may do.
  • Lab 4 · after Session 4
    Optimise
    Golden evals, BigQuery Agent Analytics, traces, eval-gated deploys — measure and improve it.
